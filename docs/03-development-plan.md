# 03. 개발 계획 (로드맵)

## 제품 포지셔닝
> **jojo — 진짜 사람만, 정직하게, 실제 만남까지.**

### 확정된 방향 (2026-10-12)
- **시장**: 한국과 글로벌 동시 출시. 처음부터 한국어·영어를 지원하고, 국내는 본인인증과 PortOne, 해외는 Stripe를 쓴다.
- **연애 목적**: 목적 구분 없이 열어둔다(틴더식). 대신 사용자가 진지한 연애, 가벼운 만남, 친구 등 자신의 목적을 밝히고, 같은 목적끼리 우선 추천한다.
- **"내가 먼저" 모드**: 사용자가 켜고 끌 수 있는 옵션으로 제공한다. 기본값은 꺼짐.

- Tinder에서 가져올 것: 직관적인 스와이프 UX, 빠른 온보딩
- Bumble에서 가져올 것: 여성 안전 장치("내가 먼저" 모드를 **옵션**으로), 이후 친구 찾기 모드(BFF)
- 버릴 것: 좋아요 페이월, 무한 스와이프, 불투명한 정지, 결제 여부에 따른 노출 차별

## North Star 지표
**주간 "실제 만남" 수**: 매칭 → 대화 10턴 이상 → 만남 제안 수락 → 만남 후 체크인 응답 "만났어요"

보조 지표

| 지표 | 목표 (베타) |
|---|---|
| 가입 → 인증 완료율 | ≥ 70% |
| 매칭 → 첫 메시지율 | ≥ 60% |
| 신고 처리 SLA (72시간) 준수율 | ≥ 95% |
| 스캠 신고 / 1,000 매칭 | 지속 감소 |
| 구독 해지 후 환불 분쟁 | 0건 목표 |

## Phase 1 — MVP 핵심 루프 (6~8주)
**목표: 인증된 사람끼리 매칭되고 대화할 수 있다.**

1. **온보딩 & 인증** (2주)
   - 휴대폰 OTP / Apple / Google / Kakao 로그인
   - 본인인증 (성인 확인, CI 기반 중복 가입 차단)
   - 얼굴 라이브니스 인증 + 프로필 사진 대조. **통과해야 덱에 노출**
   - 프로필: 사진 3~6장, 질문형 프롬프트 3개, 기본 정보, 연애 목적(intent)
2. **디스커버리** (2주)
   - 하루 큐레이션 큐 (예: 하루 15명). 거리·나이·선호·활동성·상호 선호도로 점수 계산
   - 카드마다 "왜 추천됐나요?" 표시
   - 스와이프 카드 UI (웹: 드래그 + 키보드, 앱: 제스처)
   - 14일 미접속 계정은 큐에서 제외
3. **매칭 & 채팅** (2주)
   - 상호 좋아요 → 매칭. **받은 좋아요 목록은 무료로 공개**
   - 실시간 채팅, 읽음 표시, 푸시 알림
   - 첫 사진은 자동 블러 처리 (탭해야 보임)
   - 아이스브레이커 제안 (상대 프롬프트 기반)
   - "정중한 마감" 버튼, 72시간 무응답 시 정리 안내
   - 선택형 "내가 먼저 메시지" 모드
4. **기본 안전** (1주)
   - 신고(증거 메시지/사진 첨부) / 차단 / 매칭 해제
   - 이미지 업로드 자동 모더레이션
   - 앱 내 계정 삭제
5. **웹** — 앱과 같은 기능 + SEO 랜딩, 대기 등록, 이용약관·개인정보처리방침 페이지

## Phase 2 — 신뢰 & 안전 고도화 (3~4주)
- [ ] 스캠 메시지 감지: 외부 메신저 ID, 송금, 계좌, 코인/투자, 링크 패턴 → 경고 배너 + 위험 점수
- [ ] 모더레이션 어드민 콘솔: 신고 큐, 증거 열람, 스트라이크 부여, 처리 SLA 대시보드
- [ ] 스트라이크 단계 (경고 → 7일 기능 제한 → 정지) + 사용자에게 구체적 사유 고지
- [ ] 항소 센터: 사람이 검토, 72시간 내 결정, 결정 사유 회신
- [ ] 신고 남용 방지: 신고 건수만으로 자동 정지하지 않음, 신고자 신뢰도 가중치
- [ ] 다중 계정·기기 탐지 (CI, 기기 지문)

## Phase 3 — 정직한 수익화 (3주)
- [ ] RevenueCat 연동 (iOS/Android), Stripe/PortOne 웹 결제
- [ ] **jojo Plus** (편의 기능 위주): 확장 필터(키·학력·흡연 등), 되돌리기, 여행 모드, 큐 +10명/일, 읽음 확인
  - **유료로 팔지 않는 것**: 받은 좋아요 보기, 추천 순위 상승, 메시지 보내기
- [ ] 갱신 3일 전 푸시 + 이메일 알림, 원탭 해지 동선
- [ ] 정지 시 잔여 기간 비례 환불 (웹 결제), 스토어 결제는 환불 요청 안내
- [ ] 가격 정책 공개 페이지 ("결제해도 추천 순위는 바뀌지 않습니다")

## Phase 4 — 클로즈드 베타 & 스토어 출시 (4주)
- [ ] 서울 한정 초대제 베타 (목표 1,000~3,000명), 대기열로 성비 관리
- [ ] 만남 제안 카드 (장소·시간 투표) + 만남 후 체크인 ("만났어요 / 안전했나요?")
- [ ] 안전 기능: 만남 일정 지인 공유, 긴급 신고
- [ ] App Store / Play Store 심사 준비: 데모 계정, UGC 정책, 계정 삭제, 개인정보 라벨
- [ ] 위치기반서비스사업자 신고 등 법적 절차 완료
- [ ] 투명성 리포트 v1 (가짜 계정 차단 수, 신고 처리 시간)

## Phase 5 — 확장 (출시 이후)
- 친구 찾기 모드 (Bumble BFF 참고)
- 영상통화 (만남 전 확인용)
- 관심사 기반 소규모 오프라인 이벤트
- 글로벌 확장 (영어, Stripe, 지역별 성비 게이팅)
- 추천 모델 고도화 (실제 만남 성공 데이터로 학습)

## 리스크 & 대응

| 리스크 | 대응 |
|---|---|
| 초기 유저 부족 (콜드 스타트) | 지역 한정 + 초대제로 밀도 확보, 대기열을 마케팅에 활용 |
| 성비 불균형 | 성비 게이팅, 여성 안전 기능을 핵심 마케팅 메시지로 |
| 인증 단계에서 이탈 | 인증 이유를 온보딩에서 설명 ("모두가 인증했어요"), UX 최적화와 A/B 테스트 |
| 좋아요 무료 공개로 매출 감소 | 편의 기능 구독 + 신뢰를 통한 장기 유지로 LTV 확보. Phase 3에서 가격 실험 |
| 스토어 심사 거절 | UGC·데이팅 정책 체크리스트를 Phase 1부터 반영 |
| 얼굴 인증 비용 | 가입 1회 + 사진 변경 시에만 실행, 건당 비용 모니터링 |
