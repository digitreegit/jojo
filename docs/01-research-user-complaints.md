## 상세 분석

### 1. 가짜 프로필 · 봇 · 스캠
- 무료 사용자 쪽은 봇이, 유료 사용자 쪽은 실제 사람이 운영하는 정교한 스캠 계정이 주로 문제다.
- 리뷰에서 반복되는 패턴: "가짜 프로필은 인증을 통과하는데 진짜 사용자는 인증에 실패한다."
- Bumble의 "여성이 먼저 메시지" 정책은 괴롭힘을 줄였지만 봇은 막지 못했다.
- 국내: 아만다·너랑나랑 운영사 테크랩스가 2021~22년 가짜 여성 계정으로 남성 회원에게 호감을 표시해 결제를 유도했고, 공정위가 과징금 5,200만 원을 부과했다. **업계 전체에 대한 불신의 원인**이 됐다.

### 2. 결제 구조
- "나를 좋아한 사람 보기"를 유료로 막아두면, 플랫폼 입장에서는 봇 좋아요라도 숫자가 커지는 게 이익이 된다. **구조적으로 봇을 방치할 유인**이 생기는 셈이다.
- 최상위 구독료가 넷플릭스·스포티파이·디즈니+를 합친 것보다 비싸다 (Tinder 연간 최대 약 $720).
- 국내 앱은 재화(하트·리본) 차감 방식이라, 한 명에게 말을 걸려고 해도 5천 원 이상이 든다.

### 3. 계정 정지 / 모더레이션
- 신고 몇 건만으로 자동 정지되는 것으로 보인다 ("답장을 늦게 했더니 가짜라고 신고당해 정지").
- 항소 센터는 있지만 사유가 구체적이지 않고, 결과만 승인/거절로 통보된다.
- 결제 직후 정지되고 환불도 거부되니 "돈만 받고 쫓아낸다"는 인식이 생긴다.

### 4. 번아웃 / 대화 단절
- 무한 스와이프 탓에 자신이 "수많은 프로필 중 하나"로 느껴지고, 자존감이 떨어진다 (이탈 사유의 16.9%).
- 사람들을 지치게 하는 건 거절 자체보다 **애매함**이다. 잘 대화하다가 연락이 끊기는 열린 결말이 깔끔한 거절보다 더 피곤하다.
- 67%의 여성과 61%의 남성이 "상대가 좋아요 전에 내 프로필 전체를 봐주길" 원한다. 사람들이 느린 탐색을 원하고 있다는 뜻이다.

### 5. 국내 시장 특수성
- 얼굴 인증을 하는 앱(위피·글램)이 인증 없는 틴더보다 평가가 좋다. **인증은 국내에서 필수 기대치**다.
- 재화를 무료로 얻기 어려울수록 남성 사용자 불만이 커지고, 여성 사용자에게 혜택을 몰아주는 구조가 고착된다.

| 불만 | jojo 원칙 | 구체 기능 |
|---|---|---|
| 가짜/봇/스캠 | **전원 실사용자 인증** | 가입 시 얼굴 라이브니스 인증 필수 + 프로필 사진과 얼굴 대조. 국내는 휴대폰 본인인증(성인 확인)도 필수. 인증 없이는 덱에 노출되지 않음 |
| | **스캠 실시간 감지** | 메시지에서 외부 메신저 유도·송금·코인·투자 패턴을 AI로 감지 → 수신자에게 경고 배너, 반복되면 자동 검토 큐로 |
| | **운영사 가짜 계정 0 선언** | 이용약관과 공개 정책에 명시하고 정기 투명성 리포트 발행 |
| 결제 함정 | **좋아요는 무료로 공개** | "나를 좋아한 사람"을 페이월로 막지 않음 → 봇을 방치할 유인 제거 |
| | **정직한 구독** | 갱신 3일 전 알림, 원탭 해지, 계정 삭제 시 구독 해지 안내 강제, 정지 시 잔여 기간 비례 환불(웹 결제 기준. 스토어 결제는 환불 요청 동선을 안내) |
